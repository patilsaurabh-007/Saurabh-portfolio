# Saurabh Patil — Engineering Student & Developer Portfolio

A modern, responsive, high-performance personal portfolio website built for **Saurabh Patil**, Engineering Student at R. C. Patel Institute of Technology, Shirpur (Maharashtra, India).

## 🚀 Features

- **Responsive & Modern Design:** Crafted using HTML5, CSS3 with responsive Grid and Flexbox layouts.
- **Bespoke Multi-Layer Background:** Dynamic tech blueprint grid, organic floating aurora gradient meshes, tactile stippled film texture, and an interactive mouse spotlight follower.
- **Dark & Light Mode:** Toggleable color theme with automatic `localStorage` persistence and preference detection.
- **Interactive Code Terminal Card:** Visual developer JSON card highlighting tech stack, location, and focus areas.
- **Featured Project Showcase (CampusPay):**
  - Dedicated architecture breakdown and live simulated ledger UI.
  - Interactive deep-dive modal featuring SQL schema definitions and engineering highlights.
- **Skills Matrix:** Divided into four clear domains (Programming, Web Development, Databases, Tools & Platforms).
- **Academic Background:** Detailed timeline for R. C. Patel Institute of Technology (Shirpur, Maharashtra).
- **Interactive Contact Section:**
  - One-click "Copy to Clipboard" buttons for email and phone number with toast notifications.
  - Functional contact form triggering direct email composition.
- **Integrated Resume / CV View:**
  - In-browser modal resume preview.
  - One-click print / PDF export with print-optimized CSS styles (`@media print`).
- **Zero Heavy Dependencies:** Lightweight, vanilla JavaScript and CSS, ultra-fast load times.

## 🌐 Quick Start (Local Preview)

Simply open `index.html` in any modern web browser:

- Double-click `index.html`, OR
- Run a simple local HTTP server:
  ```bash
  # Using Python
  python -m http.server 8000

  # Or using Node.js
  npx serve
  ```
  Then open [http://localhost:8000](http://localhost:8000).

## 🚢 Deploying to GitHub Pages (Free)

1. Create a new GitHub repository named `patilsaurabh007.github.io` (or any repository name).
2. Initialize and push this folder:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio release"
   git branch -M main
   git remote add origin https://github.com/patilsaurabh007/<repo-name>.git
   git push -u origin main
   ```
3. In repository **Settings** > **Pages**, set branch to `main` and save.
4. Your portfolio will be live at `https://patilsaurabh007.github.io/`!
